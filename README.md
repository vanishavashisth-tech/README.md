🛒 LUXE - Your Ultimate Shopping Companion

A simple, responsive product listing web app built using HTML, CSS, and JavaScript.
LUXE fetches real product data from a public API and allows users to explore, search, and manage products smoothly.


About
LUXE is a front-end project created to practice core JavaScript concepts like:
	•	API integration
	•	Asynchronous programming
	•	Array methods (map, filter, sort)


The app displays products in a clean and user-friendly interface, allowing users to interact with them through various features like search, filtering, and cart management.


Features
•	Search products by title
•	Filter products by category
• Sort products by price and rating
•	Add products to cart
•	Increase / decrease product quantity in cart
•	Save (wishlist) functionality
•	Responsive design for all screen sizes


API Used
•	Fake Store API
•	Endpoint: https://fakestoreapi.com/


Concepts Covered
•	API Integration using fetch()
•	Asynchronous JavaScript (async/await)
•	Array methods:
•	map()
•	filter()
•	sort()
•	DOM Manipulation
•	Event Handling
•	Local Storage (for cart & saved items)


Technologies Used
•	HTML
•	CSS
•	JavaScript (ES6+)

Project Goals
•	Learn how to integrate APIs using fetch()
•	Practice JavaScript array methods
•	Build a responsive and clean UI
•	Handle user interactions effectively
